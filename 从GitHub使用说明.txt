发文张 · 从 GitHub / 微信 打开后怎么用
========================================

【重要】微信里点 GitHub 链接，不能直接“打开网站”或运行 启动网站.bat！
GitHub 只是代码仓库，程序必须在您自己的 Windows 电脑上安装后运行。

一、需要什么
------------
1. 一台 Windows 电脑（Win10 / Win11）
2. 已安装 Node.js（https://nodejs.org/ 下载 LTS 版，一路下一步）
3. 不要用手机打开 .bat（手机无法运行本工具）

二、正确下载步骤（发给朋友也按这个做）
--------------------------------------
1. 用电脑浏览器打开 GitHub 仓库地址（不要用微信内置浏览器下载）
   推荐：Chrome / Edge 复制链接到地址栏打开

2. 点击绿色按钮 「Code」→ 「Download ZIP」

3. 把 ZIP 解压到任意文件夹
   例如：D:\发文张\fawenzhang-main\
   ※ 必须在解压后的文件夹里双击 bat，不要隔着 ZIP 点！

4. 进入解压后的文件夹，双击：
   「启动网站.bat」
   首次会安装依赖，等 1～3 分钟，浏览器会自动打开页面

5. 以后每次使用可双击：
   「打开网页.bat」（更快）

三、若提示“无法打开”或闪退
----------------------------
1. 确认已安装 Node.js：开始菜单输入 cmd，输入 node -v 有版本号即可
2. 右键「启动网站.bat」→ 以管理员身份运行
3. 右键 bat → 属性 → 若有「解除锁定」请勾选后确定
4. 杀毒软件可能拦截，请允许本文件夹
5. 路径不要有奇怪符号，尽量放在 D:\发文张\ 这类英文或中文短路径

四、不能做的事
--------------
× 在微信里点开 GitHub 上的 启动网站.bat（只会看代码，不会运行）
× 用手机运行 .bat
× 只下载 index.html 不下载整个项目
× 不装 Node.js 就双击 bat

五、分享给别人的话术（可复制到微信）
------------------------------------
这是 Windows 电脑本地工具，请用电脑浏览器打开 GitHub 链接 → Code → Download ZIP → 解压 → 双击「启动网站.bat」。需先安装 Node.js。手机无法使用。
